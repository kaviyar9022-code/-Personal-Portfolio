# Kaviya R - Portfolio

Personal portfolio website.

## Run
Open `index.html` in any browser. No build step needed.

## Files
- `index.html` - page content
- `style.css` - styles (light and dark theme)
- `script.js` - copy-email button

Fonts load from Google Fonts, so an internet connection is needed to see them; the page falls back to system fonts offline.
